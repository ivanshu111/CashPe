# API Test Cases for Budget and Expense Tracker Module

## Pre-requisites:
*   A registered user and their authentication token.
*   An admin user and their authentication token (for global category creation).

## General Test Principles:
*   All requests require an `Authorization: Bearer <TOKEN>` header.
*   Replace `<USER_TOKEN>` and `<ADMIN_TOKEN>` with actual valid JWT tokens obtained after user login.
*   Replace `<USER_ID>` with the actual ID of the logged-in user.
*   Replace `<CATEGORY_ID>`, `<BUDGET_ID>`, `<EXPENSE_ID>` with IDs obtained from successful creation requests.
*   Use a tool like Postman, Insomnia, or `curl` to execute these API requests.

## 1. Category API Tests (`/api/categories`)

### 1.1. Add Category (POST /api/categories) ✅✅✅
*   **Test Case 1.1.1: Create a user-specific category successfully**
    *   **Description:** A regular user adds a new category for their expenses.
    *   **Request:** `POST /api/categories`
    *   **Headers:** `Authorization: Bearer <USER_TOKEN>`
    *   **Body:** `{ "name": "Groceries" }`
    *   **Expected:** `201 Created`, JSON object containing the new category. Verify `category.name` is "Groceries" and `category.userId` matches `<USER_ID>`.
*   **Test Case 1.1.2: Create another user-specific category**
    *   **Description:** A regular user adds a second distinct category.
    *   **Request:** `POST /api/categories`
    *   **Headers:** `Authorization: Bearer <USER_TOKEN>`
    *   **Body:** `{ "name": "Rent" }`
    *   **Expected:** `201 Created`, JSON object containing the new category.
*   **Test Case 1.1.3: Attempt to create a duplicate user-specific category**
    *   **Description:** A user tries to add a category with a name they already own.
    *   **Request:** `POST /api/categories`
    *   **Headers:** `Authorization: Bearer <USER_TOKEN>`
    *   **Body:** `{ "name": "Groceries" }`
    *   **Expected:** `400 Bad Request`, error message like "Category with this name already exists for you."
*   **Test Case 1.1.4: Create a global category (as Admin)**
    *   **Description:** An admin user creates a category accessible to all users.
    *   **Request:** `POST /api/categories`
    *   **Headers:** `Authorization: Bearer <ADMIN_TOKEN>`
    *   **Body:** `{ "name": "Utilities (Global)", "isGlobal": true }`
    *   **Expected:** `201 Created`, JSON object containing the new category. Verify `category.name` is "Utilities (Global)" and `category.userId` is `null`.
*   **Test Case 1.1.5: Attempt to create a global category (as regular user)**
    *   **Description:** A regular user tries to create a global category. The system should default it to a user-specific category.
    *   **Request:** `POST /api/categories`
    *   **Headers:** `Authorization: Bearer <USER_TOKEN>`
    *   **Body:** `{ "name": "Global Attempt", "isGlobal": true }`
    *   **Expected:** `201 Created`, JSON object containing the new category. Verify `category.name` is "Global Attempt" and `category.userId` matches `<USER_ID>`.
*   **Test Case 1.1.6: Invalid category name (empty)**
    *   **Description:** Attempt to create a category with an empty name.
    *   **Request:** `POST /api/categories`
    *   **Headers:** `Authorization: Bearer <USER_TOKEN>`
    *   **Body:** `{ "name": "" }`
    *   **Expected:** `400 Bad Request`, error message like "Category name is required."
