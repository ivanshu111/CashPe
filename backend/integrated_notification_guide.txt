# Guide: Integrating a Real-Time Notification System in Your Existing Project

This guide details how to implement a notification system using MongoDB, Redis, and Socket.IO directly into your existing `CashPe` backend.

---

## Step 1: Install New Dependencies ✅✅

Open your terminal in the `D:\CashPe\backend` directory and run the following command:

```bash
npm install socket.io ioredis
```

---

## Step 2: Update Environment Variables

You likely have a `.env` file for your `MONGO_URI`. Add your Redis connection string to it. If you don't have a `.env` file, create one in the root directory.

```.env
# Keep your existing variables
MONGO_URI=mongodb://localhost:27017/yourDB
PORT=yourPort

# Add the Redis URI
REDIS_URI=redis://localhost:6379
```

---

## Step 3: Create the Notification Model

Create a new file to define the schema for notifications.

**File: `src/models/Notification.js`**
```javascript
const mongoose = require('mongoose');

const notificationSchema = new mongoose.Schema({
  userId: {
    type: mongoose.Schema.Types.ObjectId,
    ref: 'User', // This links to your existing User model
    required: true,
  },
  message: {
    type: String,
    required: true,
  },
  isRead: {
    type: Boolean,
    default: false,
  },
  createdAt: {
    type: Date,
    default: Date.now,
  },
});

const Notification = mongoose.model('Notification', notificationSchema);

module.exports = Notification;
```

---

## Step 4: Create Notification Services

Create a new directory `src/services` to hold the logic for managing Redis and Socket.IO.

1.  **Create the directory:** `src/services`

2.  **Create the Redis Manager:**
    **File: `src/services/redisManager.js`**
    ```javascript
    const IORedis = require('ioredis');
    // Assuming you use dotenv in app.js, process.env will be populated
    
    const publisher = new IORedis(process.env.REDIS_URI);
    const subscriber = new IORedis(process.env.REDIS_URI);
    
    const NOTIFICATION_CHANNEL = 'notifications';
    
    /**
     * Publishes a new notification to the Redis channel.
     */
    const publishNotification = (notification) => {
      console.log(`Publishing notification for user ${notification.userId}`);
      publisher.publish(NOTIFICATION_CHANNEL, JSON.stringify(notification));
    };
    
    module.exports = {
      subscriber,
      publishNotification,
      NOTIFICATION_CHANNEL,
    };
    ```

3.  **Create the Socket.IO Manager:** ✅✅✅
    **File: `src/services/socketManager.js`**
    ```javascript
    const { Server } = require('socket.io');

    let io;

    const initSocketManager = (server) => {
      io = new Server(server, {
        cors: {
          origin: '*', // TODO: Restrict this to your frontend's domain in production
        },
      });

      io.on('connection', (socket) => {
        console.log(`New client connected: ${socket.id}`);

        // A client must emit 'register' with their userId to receive notifications
        socket.on('register', (userId) => {
          if (userId) {
            console.log(`Registering user ${userId} to their notification room.`);
            // Each user joins a "room" named after their own userId.
            socket.join(userId);
          }
        });

        socket.on('disconnect', () => {
          console.log(`Client disconnected: ${socket.id}`);
        });
      });

      console.log('Socket.IO manager initialized.');
      return io;
    };
    
    /**
     * Emits a notification event to a specific user's room.
     */
    const emitNotificationToUser = (userId, notification) => {
      if (io && userId) {
        io.to(userId).emit('new_notification', notification);
      }
    };

    module.exports = {
      initSocketManager,
      emitNotificationToUser,
    };
    ```

## Step 5: Create the Notification Controller ✅✅✅

Create a new controller alongside your existing ones.

**File: `src/controllers/notificationController.js`**
```javascript
const Notification = require('../models/Notification');
const { publishNotification } = require('../services/redisManager');

// This function is for creating a notification manually via an API endpoint.
// In practice, you'll call publishNotification from other controllers (see Step 8).
const createNotification = async (req, res) => {
  try {
    const { userId, message } = req.body;
    if (!userId || !message) {
      return res.status(400).json({ error: 'userId and message are required.' });
    }

    const newNotification = new Notification({ userId, message });
    await newNotification.save();

    // Publish the notification to Redis. The subscriber in app.js will handle sending it.
    publishNotification(newNotification.toObject());

    res.status(201).json({ message: 'Notification created successfully.', notification: newNotification });
  } catch (error) {
    res.status(500).json({ error: 'Internal server error.' });
  }
};

// Gets notification history for a user
const getUserNotifications = async (req, res) => {
    try {
        const { userId } = req.params;
        const notifications = await Notification.find({ userId }).sort({ createdAt: -1 });
        res.status(200).json(notifications);
    } catch (error) {
        res.status(500).json({ error: 'Internal server error.' });
    }
};

module.exports = {
  createNotification,
  getUserNotifications,
};
```

---

## Step 6: Create Notification Routes

Create a new routes file.

**File: `src/routes/notificationRoutes.js`**
```javascript
const express = require('express');
const router = express.Router();
const { createNotification, getUserNotifications } = require('../controllers/notificationController');
const authMiddleware = require('../middlewares/auth'); // Assuming you have this

// This endpoint is for testing or manual creation.
router.post('/', authMiddleware, createNotification);

// This endpoint gets notification history for the logged-in user.
router.get('/:userId', authMiddleware, getUserNotifications);

module.exports = router;
```

---

## Step 7: Modify `src/app.js` to Integrate Everything

This is the most critical step. You need to modify your main application file to initialize and manage the new services.

**File: `src/app.js` (Modify this file)**
```javascript
// --- At the top, add these imports ---
const http = require('http'); // Add this
const { initSocketManager, emitNotificationToUser } = require('./services/socketManager');
const { subscriber, NOTIFICATION_CHANNEL } = require('./services/redisManager');
const notificationRoutes = require('./routes/notificationRoutes'); // Add this

// --- After you initialize your express app `const app = express();` ---
const server = http.createServer(app); // Create an http server from the app

// --- Initialize Socket.IO and pass it the http server ---
initSocketManager(server);

// --- Add the Redis Subscriber logic ---
subscriber.subscribe(NOTIFICATION_CHANNEL, (err, count) => {
  if (err) {
    console.error('Failed to subscribe to Redis channel:', err);
    return;
  }
  console.log(`Subscribed to ${count} Redis channel(s) for notifications.`);
});

subscriber.on('message', (channel, message) => {
  if (channel === NOTIFICATION_CHANNEL) {
    const notification = JSON.parse(message);
    // Emit the notification to the correct user via Socket.IO
    emitNotificationToUser(notification.userId, notification);
  }
});

// --- Mount your new routes, probably with your other routes ---
app.use('/api/notifications', notificationRoutes); // Or whatever base path you use

// --- IMPORTANT: Change how you start the server ---
// Find your existing app.listen(...) and replace it with this:
const PORT = process.env.PORT || 3000;
server.listen(PORT, () => { // Use `server.listen` instead of `app.listen`
  console.log(`Server is running on http://localhost:${PORT}`);
});
```

## Step 8: Trigger Notifications From Your Code

Now, you can trigger notifications from anywhere in your backend. For example, you can notify a user after a successful transaction.

**Example: Modify `src/controllers/transactionController.js`**
```javascript
// At the top of the file, import the publishNotification function
const { publishNotification } = require('../services/redisManager');
const Notification = require('../models/Notification'); // Also import the model

// Inside your function that creates a transaction, after it's saved successfully:
// ...
// const newTransaction = await transaction.save();

// --- Add this logic ---
try {
    const notificationMessage = `Your transaction of $${newTransaction.amount} was successful.`;
    
    // 1. Save notification to DB for history
    const newNotification = new Notification({ 
        userId: newTransaction.userId, // or wherever the user ID is
        message: notificationMessage 
    });
    await newNotification.save();
    
    // 2. Publish to Redis to send it in real-time
    publishNotification(newNotification.toObject());

} catch (error) {
    console.error("Failed to send transaction notification:", error);
}
// ... continue with the response
```

You are now set up. When you start your server with `node src/app.js`, the Socket.IO and Redis listeners will be active. When your code calls `publishNotification`, a real-time event will be sent to the connected client.
