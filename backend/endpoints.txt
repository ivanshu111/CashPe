# CashPe Backend: API Endpoints

This document lists all the available API endpoints for the application, categorized by their main function. It assumes that these routes are prefixed with `/api` in your main `app.js` file (e.g., `/api/auth/login`).

---

### Authentication (`/api/auth`)

-   **`POST /register`**
    -   **Description:** Registers a new user. Expects `multipart/form-data` including name, email, password, phone, pin, and an optional `profilePicture` file.
    -   **Protection:** Public

-   **`POST /login`**
    -   **Description:** Logs in an existing user with email and password. Returns a JWT token upon success.
    -   **Protection:** Public

-   **`PATCH /profile`**
    -   **Description:** Updates the profile of the currently logged-in user. Can update name, password, phone, pin, and profile picture.
    -   **Protection:** Authenticated User

-   **`GET /history`**
    -   **Description:** Gets the complete transaction history (sent and received) for the currently logged-in user.
    -   **Protection:** Authenticated User

---

### User (`/api/users`)

-   **`GET /find`**
    -   **Description:** Finds a user by their email or phone number. Used to search for recipients before sending money.
    -   **Protection:** Authenticated User

-   **`POST /profile-picture`**
    -   **Description:** A dedicated route for the logged-in user to upload or change their profile picture.
    -   **Protection:** Authenticated User

-   **`DELETE /`**
    -   **Description:** Deletes the account of the currently logged-in user. Fails if the user's wallet balance is not zero.
    -   **Protection:** Authenticated User

---

### Wallet & Transactions (`/api/wallet`)

-   **`GET /balance`**
    -   **Description:** Gets the current wallet balance for the logged-in user.
    -   **Protection:** Authenticated User, PIN Verified

-   **`GET /details`**
    -   **Description:** Gets the logged-in user's name, wallet balance, and wallet creation date.
    -   **Protection:** Authenticated User, PIN Verified

-   **`POST /add-money`**
    -   **Description:** Adds money to the logged-in user's wallet. Max limit of 50,000 per transaction.
    -   **Protection:** Authenticated User

-   **`POST /send-money`**
    -   **Description:** Sends money from the logged-in user to a specified recipient (`toUser`). Max limit of 1,00,000 per transaction.
    -   **Protection:** Authenticated User, PIN Verified

---

### Notifications (`/api/notifications`)

-   **`GET /`**
    -   **Description:** Gets a list of all historical notifications for the currently logged-in user.
    -   **Protection:** Authenticated User

-   **`GET /:userId`**
    -   **Description:** Gets a list of all historical notifications for a specific user ID. Primarily for admin use.
    -   **Protection:** Authenticated User

-   **`POST /`**
    -   **Description:** Manually creates a notification. Primarily for internal testing.
    -   **Protection:** Authenticated User

---

### Admin (`/api/admin`)

-   **`GET /users`**
    -   **Description:** Gets a complete list of all users in the system.
    -   **Protection:** Admin Only

-   **`GET /transactions`**
    -   **Description:** Gets a complete list of all transactions that have occurred in the system.
    -   **Protection:** Admin Only

-   **`PUT /users/:userId/status`**
    -   **Description:** Updates a specific user's status to `active` or `inactive` (frozen). Triggers a notification to the user.
    -   **Protection:** Admin Only

-   **`GET /users/:userId/details`**
    -   **Description:** Gets a consolidated, detailed view of a single user, including their profile, wallet balance, and full transaction history.
    -   **Protection:** Admin Only
